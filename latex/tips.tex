\chapter{Tips \& Tricks }
\hypertarget{tips}{}\label{tips}\index{Tips \& Tricks@{Tips \& Tricks}}
The following tips and tricks are helpful to know.


\begin{DoxyItemize}
\item {\bfseries{Help Menu}}:\+ Test\+Stand (weirdly) has two help menus, which can be accessed via {\bfseries{F1}} and {\bfseries{Ctrl+\+F1}}. The former provides context-\/sensitive help, while the latter contains all help documentation. It is recommended that you use the full help menu ({\bfseries{Ctrl+\+F1}}).
\item {\bfseries{Running Selected Test Steps}}:\+ A set of specific test steps can be independently run, by selecting them in the Step Pane and right clicking, then selecting {\bfseries{Run Selected Steps}} from the dropdown.
\item {\bfseries{Unload All Modules}}:\+ All currently held modules (typically .dlls) can be released by selecting {\bfseries{File \texorpdfstring{$>$}{>} Unload All Modules}}.
\item {\bfseries{Reset UI Configuration}}:\+ Test\+Stand\textquotesingle{}s UI can be reset to its default state by selecting {\bfseries{View \texorpdfstring{$>$}{>} Reset UI Configuration}}.
\item {\bfseries{Lock UI Configuration}}:\+ Test\+Stand\textquotesingle{}s UI can be locked to prevent further changes. To toggle this setting, select {\bfseries{View \texorpdfstring{$>$}{>} Lock/\+\+Unlock UI Configuration}}.
\item {\bfseries{Drag \& Drop Variables}}:\+ Test\+Stand variables can easily be dragged and dropped into most menus and text boxes. For example, instead of typing "{}\+Locals.\+Example\+Long\+Variable\+Name"{} into a statement test step\textquotesingle{}s expression editor, you can simply drag the variable from the Variables Pane.
\item {\bfseries{Expression Browser}}:\+ The expression browser contains a variety of tools that can be helpful if you get stuck while writing an expression. The red checkmark button is also useful, as it checks the current expression for errors. 
\end{DoxyItemize}
