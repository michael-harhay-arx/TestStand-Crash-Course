Test\+Stand contains many step types, which can be used to build test sequences. Here are a few of the most commonly used step types:\+\hypertarget{steps_action}{}\doxysubsubsection{\texorpdfstring{Action}{Action}}\label{steps_action}
Calls a code module that does not perform a test. For example, an action step might initialize an instrument to prepare it for testing.

\hypertarget{steps_pf}{}\doxysubsubsection{\texorpdfstring{Pass/\+\+Fail}{Pass/\+\+Fail}}\label{steps_pf}
Calls a code module that makes its own pass/\+fail determination. Note that this module does not appear by default in the Insertion Palette; to insert a pass/\+fail step, right click the Steps Pane and select {\bfseries{Insert Step \texorpdfstring{$>$}{>} Tests \texorpdfstring{$>$}{>} Pass/\+\+Fail Test}}. Within this menu are a few other types of code module tests.  
\begin{DoxyImageNoCaption}%
  \doxymbox{\includegraphics[width=16cm]{pf_steptype.png}}%
\end{DoxyImageNoCaption}
\hypertarget{steps_sc}{}\doxysubsubsection{\texorpdfstring{Sequence Call}{Sequence Call}}\label{steps_sc}
Calls another sequence in the current sequence file or in another sequence file.  
\begin{DoxyImageNoCaption}%
  \doxymbox{\includegraphics[width=16cm]{seqcall_steptype.png}}%
\end{DoxyImageNoCaption}
\hypertarget{steps_statement}{}\doxysubsubsection{\texorpdfstring{Statement}{Statement}}\label{steps_statement}
Executes a Test\+Stand expression. For example, a statement step can be used to increment the value of a local variable. Note that statement steps do not return a pass/\+fail status by default; step status can be set in the Step Settings Pane under {\bfseries{Properties \texorpdfstring{$>$}{>} Expressions \texorpdfstring{$>$}{>} Status Expression}}.  
\begin{DoxyImageNoCaption}%

\end{DoxyImageNoCaption}
