\hypertarget{index_open}{}\doxysubsection{\texorpdfstring{Open Test\+Stand}{Open Test\+Stand}}\label{index_open}

\begin{DoxyEnumerate}
\item Press the Windows key and search for "{}\+Test\+Stand Version Selector"{}. Open the application.
\item Under "{}\+Installed Test\+Stand versions"{}, there will be a dropdown listing the currently installed versions. If Test\+Stand 2017 is not yet installed, talk to IT. Otherwise, select 2017.
\item Select "{}\+Make Active"{}, and then select "{}\+Launch 32-\/bit"{}.
\item When Test\+Stand launches, it will prompt you for credentials. By default, the username should be "{}administrator"{} and the password should be left blank.
\end{DoxyEnumerate}

\hypertarget{index_familiarize}{}\doxysubsection{\texorpdfstring{Familiarize Yourself}{Familiarize Yourself}}\label{index_familiarize}
Once Test\+Stand is open, select {\bfseries{View \texorpdfstring{$>$}{>} Reset UI Configuration}}. This will ensure that your UI layout is the same as described in this guide. However, the Test\+Stand UI is completely customizable and can be adjusted to your liking.

Take a few moments to familiarize yourself with the general layout of the program.  
\begin{DoxyImage}%
\includegraphics[width=0.700000\textwidth]{TestStandHome.png}%
\doxyfigcaption{Default Test\+Stand Layout}%
\end{DoxyImage}
 The interface is divided into the following panes:\+
\begin{DoxyEnumerate}
\item {\bfseries{Steps Pane}}:\+ this is where test steps are sequenced.
\item {\bfseries{Sequences Pane}}:\+ contains a list of all sequences within the sequence file.
\item {\bfseries{Insertion Palette}}:\+ contains steps that can be dragged into the steps pane.
\item {\bfseries{Step Settings Pane}}:\+ when a test step is selected, this pane can be used to view and edit step settings.
\item {\bfseries{Variables Pane}}:\+ all variables are listed here. 
\end{DoxyEnumerate}
