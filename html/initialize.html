Initial Setup

This list has some overlap with Setup Steps Before using the Sequencer found in the GUI documentation. This is the more detailed list.

  1. Clone the ArxtronTestStandSequencer with its submodules from GitHub using git clone --recurse-submodules git@github.com:ArxtronTech/ArxtronTestStandSequencer.git
  2. Create the shared libraries folder (default C:\Arxtron\Libraries)
  3. Open OneTimeSetup.seq and run the TestStandConfiguration sequence, ignore any analysis errors, but the sequence itself should pass.
  4. Rename the Test Step Type Definition by appending _[Project Name/Abbreviation]. Do the same with the Test Types
  5. Update the Configuration Files and run the Config Struct Creation sequences. This has to be done each time the configuration file structure changes
  6. Add additional directories to the search path if applicable.
  7. Add Add TESTSTAND%\Components\Models\TestStandModels\modelsupport2 to Windows system paths
